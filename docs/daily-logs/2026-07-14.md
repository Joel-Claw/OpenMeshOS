## Development Work

### AES-128-CTR Config Encryption Unit Tests

Added comprehensive unit tests for the AES-128-CTR config encryption system (added July 3 but never tested). This is security-critical code that handles encrypting user configs at rest.

**Test file**: `test/test_aes_config.cpp` — 19 tests covering:
- CTR mode round-trip: basic, empty input, exactly one block, partial block, large data
- Different IV/key producing different ciphertext (confusion/diffusion)
- Counter wrap at 0xFF boundary (CTR counter increments correctly)
- Magic header detection (OMS2 format validation)
- Full config file format simulation (magic + IV + ciphertext)
- Key derivation determinism (SHA-256(MAC || "oms-cfg-key"))
- CTR symmetric property (encrypt = decrypt)
- Non-identity (ciphertext != plaintext)
- Zero-input keystream visibility

**Implementation note**: The test uses a self-contained minimal AES-128 implementation (S-box, key expansion, encrypt block, GF multiplication) rather than the rweather/Crypto library used in production, to keep the test dependency-free.
