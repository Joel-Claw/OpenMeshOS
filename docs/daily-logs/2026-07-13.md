## Development Work

### BLE OTA Firmware Update on nRF52 (Nordic DFU Bootloader)

Implemented the BLE OTA firmware update for nRF52 platforms (RAK WisBlock RAK4631) using the Nordic DFU bootloader. This was the last remaining "no hardware" development item on the ROADMAP.

**How it works:**
- The companion app sends a trigger byte (0x01) to the firmware update BLE characteristic
- The firmware calls `BLEDfu.start()` which is built into the Adafruit Bluefruit52Lib
- BLEDfu handles: saving peer bond data, setting GPREGRET magic (0xB1), disabling SoftDevice, jumping to bootloader
- The bootloader advertises as "OpenMesh-DFU" and the companion app transfers new firmware
- After DFU, the bootloader reboots into the new app automatically

**Key design decisions:**
- Used Adafruit BLEDfu service (built into Bluefruit52Lib) rather than implementing DFU protocol from scratch
- Same companion app API works across ESP32 and nRF52 (0x01 = trigger, 0x02 = cancel, 0x03 = query state)
- ESP32 OTA: app handles the entire write via Update class
- nRF52 OTA: Nordic DFU bootloader handles the transfer, app just triggers it
- OTA abort timeout (5s) resets state if DFU reboot doesn't happen
