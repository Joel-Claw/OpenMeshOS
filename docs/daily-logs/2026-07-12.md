### RAK4631 Unit Test Expansion

Expanded the RAK4631 unit tests in `test/test_iboard.cpp` with additional pin coverage:

**New tests added:**
- LORA_POWER_EN pin (37) — unique to RAK4631, not on T-Deck or Heltec V3
- WisBlock IO slot pins (WB_IO1=17, WB_IO2=34)
- I2C bus 2 pins (I2C2_SDA=24, I2C2_SCL=25) — for IO slot peripherals
- SPI bus pins (SPI_CS=26, SPI_SCK=3, SPI_MISO=29, SPI_MOSI=30)
- GPS pins (GPS_RX=15, GPS_TX=16) — optional external on UART1
- I2C1/OLED bus consistency check (same physical bus, SDA=13, SCL=14)

**Bug fix:**
- Renamed LED pin constants in test namespace from `LED_BLUE`/`LED_GREEN` to `LED_BLUE_PIN`/`LED_GREEN_PIN` to match the actual `BoardRAK4631.h` header. The header was renamed in the July 11 session to avoid clashing with nRF52 `variant.h` macros that `#define LED_BLUE` and `LED_GREEN`. The test namespace had stale names.
