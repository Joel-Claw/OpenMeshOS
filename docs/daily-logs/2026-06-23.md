## Development Work

### Commits Made
1. `a0c6721` — feat: periodic advert timer in MeshService (5min +/- 1min jitter)
   - **What**: Added periodic self-advert sending to MeshService::tick()
   - **Why**: Other mesh nodes can only discover us if we broadcast adverts.
     Without this, we receive adverts from others but never announce ourselves.
   - **How**: Every 5 minutes (with +/- 1 minute random jitter to avoid
     synchronised advert storms), MeshService calls OpenMeshChat::sendAdvert().
     The jitter is recomputed each cycle using esp_random() for continuous
     desynchronisation. First advert fires 5 minutes after boot.
   - **Files**: MeshService.h (new members + constants), MeshService.cpp (tick logic)
   - **Build**: t-deck PASS (Flash: 25.1%), heltec-v3 PASS (Flash: 18.0%)
