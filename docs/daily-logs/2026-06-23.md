## Development Work

### Major Refactor: MeshService → OpenMeshChat Integration

This is the most significant change since the IBoard migration. MeshService now
uses OpenMeshChat (BaseChatMesh subclass) instead of OpenMesh (raw Mesh subclass).

**What changed:**
- MeshService.cpp: replaced OpenMesh* with OpenMeshChat*
- Identity loading/generation now handled by OpenMeshChat::begin() instead of
  MeshService doing it manually
- Contact persistence handled by OpenMeshChat (saveContacts/loadContacts)
- Message callback bridge: OpenMeshChat::onMessageReceived → onChatMessage()
  → MessageBus::inbox().push() → UI screens (unchanged)
- NodeTracker fed from OpenMeshChat::onDiscoveredContact (was OpenMesh::onAdvertRecv)
- sendChannel() now uses OpenMeshChat::sendChannelMessage() (PSK-encrypted group channel)
- sendDirect() now uses OpenMeshChat::sendDirectMessage() (with contact lookup, ACKs)
- OpenMeshChat constructor changed from StdRNG& to mesh::RNG& to accept RadioNoiseListener
- MeshService.h: added chat() accessor, OpenMeshChat forward declaration

**What stayed the same:**
- MeshService public API (sendChannel, sendDirect, rssi, nodeCount, hopCount, initialized)
- UI screens (ScreenHome, ScreenLock, ScreenScanner, ScreenSettings, ScreenTerminal) — no changes needed
- MessageBus structure and API
- NodeTracker API
- Notification system (beep + wake on incoming message)
