#### Key architectural notes:
- RAK4631 is fundamentally different from ESP32 targets:
  - nRF52840 is ARM Cortex-M4F (not Xtensa LX7)
  - 64MHz clock (vs 240MHz on ESP32-S3)
  - 256KB RAM (vs 512KB + 8MB PSRAM on T-Deck)
  - 1MB flash (vs 16MB on T-Deck)
  - BLE 5.0 via Nordic SoftDevice (vs ESP32 BLE stack)
  - No WiFi at all (ESP32 has WiFi)
  - Internal flash (vs external SPI flash)
- Despite constraints, RAK4631 is excellent for:
  - Low-power repeater nodes (battery life measured in months)
  - Solar-powered remote nodes (nRF52 designed for IoT)
  - BLE companion mode (superior BLE to ESP32)
  - Sensor nodes (WisBlock ecosystem has many sensors)

### Platform Abstraction Layer (nRF52 Adaptation)
**Status: Complete — Config, MeshService, HeapMonitor all abstracted**

Created `src/hardware/PlatformCompat.h` and `PlatformCompat.cpp` to provide a unified API for platform-specific operations:

- `platform::readMacAddress(uint8_t mac[6])` — ESP32 uses `esp_read_mac()`, nRF52 reads FICR DEVICEID registers
- `platform::fillRandom(uint8_t* buf, size_t len)` — ESP32 uses `esp_random()`, nRF52 uses hardware RNG peripheral (polling mode)
- `platform::freeHeap()` — ESP32 uses `esp_get_free_heap_size()`, nRF52 uses `xPortGetFreeHeapSize()`
- `platform::minFreeHeap()` — ESP32 uses `esp_get_minimum_free_heap_size()`, nRF52 tracks manually (FreeRTOS doesn't provide a watermark)
- `platform::largestFreeBlock()` — ESP32 uses `heap_caps_get_largest_free_block()`, nRF52 approximates with `xPortGetFreeHeapSize()`

Files updated:
1. **Config.cpp** — Replaced `#include <esp_mac.h>` with `PlatformCompat.h`, `esp_read_mac()` → `platform::readMacAddress()`
2. **MeshService.cpp** — Replaced `#include <esp_system.h>` with `PlatformCompat.h`, `esp_random()` → `platform::fillRandom()`
3. **HeapMonitor.cpp** — Replaced `#include <esp_heap_caps.h>` with `PlatformCompat.h`, `esp_get_free_heap_size()` → `platform::freeHeap()`, `esp_get_minimum_free_heap_size()` → `platform::minFreeHeap()`, `heap_caps_get_largest_free_block()` → `platform::largestFreeBlock()`
