### AES-128-CTR Config Encryption (completed)
Upgraded config encryption from XOR obfuscation to AES-128-CTR using the `rweather/Crypto` library.

**Changes to `src/utils/Config.cpp`:**
- Replaced XOR obfuscation with AES-128-CTR encryption
- Key derived from SHA-256(device MAC || "oms-cfg-key"), first 16 bytes used as AES-128 key
- Random IV generated per save using platform RNG
- File format: `[4-byte magic "OMS2"] [16-byte IV] [AES-CTR ciphertext]`
- Auto-migration from old XOR-obfuscated and plaintext formats on first load
- Legacy XOR function retained for migration detection only
- Uses `AES128` and `SHA256` classes from the Crypto library (already a dependency)
- CTR mode chosen: no padding overhead, stream cipher, same ciphertext length as plaintext

**Security improvement:**
- Old: XOR with device-derived key (trivially reversible if key extraction possible)
- New: AES-128-CTR with SHA-256-derived key + random IV per write
- Key derivation uses domain separator ("oms-cfg-key") to prevent cross-protocol key reuse
- IV randomness prevents identical plaintext producing identical ciphertext
