## Development Work

### JSON Parser Fix + Config Validation Tests

**Bug found**: Config.cpp's `save()` function writes JSON with spaces after
colons (e.g. `"radioRegion": "EU868"`) but `findJsonString` only searched
for the compact pattern `"key":"`. This meant the parser could not read
back string fields from its own saved config files. Integer and boolean
parsers already had whitespace skipping; only the string parser was missing it.

**Fix**: Updated `findJsonString` in Config.cpp to search for `"key":` then
skip whitespace before expecting the opening quote, matching the pattern
already used by `findJsonInt` and `findJsonBool`.

**Tests**: Added `test/test_config_validation.cpp` with 107 host-side tests:
- JSON string parsing (compact, spaced, escapes, truncation, empty)
- JSON integer parsing (basic, negative, zero, whitespace, defaults)
- JSON boolean parsing (true, false, defaults, invalid)
- Full config round-trip parse (all fields)
- Callsign sanitization (valid, injection stripping, empty default, truncation)
- Region validation (all valid regions, invalid rejected)
- TX power clamping (in-range, out-of-range)
- Radio region lookup (known, unknown fallback, all regions valid)
- JSON injection edge cases (callsign injection, escape abuse, empty key, partial)

**Results**: All 107 tests pass. Full test suite: 9/9 passed, 2 skipped.

Committed as `886aee3` on `dev` branch.
